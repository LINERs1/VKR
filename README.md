# Образовательная платформа с ИИ-ассистентом

Минимальный работающий прототип обучающей платформы.
Реализован вертикальный срез: выбор урока → чтение текста → чат с ИИ-ассистентом по тексту урока.

## Функционал
- **3+ урока** (тексты подтягиваются из markdown-файлов в `backend/data/course_docs/`).
- **ИИ-тьютор**: работает локально через Ollama, отвечает строго по контексту выбранного урока. **Не выдаёт прямой ответ сразу**, а выступает в роли тьютора: задаёт наводящие вопросы и помогает студенту прийти к правильному выводу. Отказывается отвечать на темы вне урока.
- **Единая страница**: текст урока и чат на одном экране, без перехода по вкладкам.

## Технологии
- **Backend**: Python / FastAPI (выбран вместо Go, так как фреймворк отлично подходит для RAG и ИИ задач)
- **Frontend**: Vue.js 3
- **LLM**: Ollama (`qwen2.5:latest`)
- **База данных**: ChromaDB для векторного поиска (локальная)

## Как запустить (Локально без Docker)

1. Убедитесь, что установлена и запущена **Ollama**. Для скачивания моделей:
   ```bash
   ollama pull qwen2.5:latest
   ollama pull nomic-embed-text
   ```
2. Запустите скрипт `start.bat` из корня проекта. Он автоматически поднимет бэкенд и фронтенд в двух разных окнах терминала.
3. Откройте `http://localhost:5173`.

## Как запустить (Docker)

1. Убедитесь, что Ollama запущена на вашем хосте.
2. Соберите образ:
   ```bash
   docker build -t edu-platform .
   ```
3. Запустите контейнер (прокидываем доступ к Ollama через `host.docker.internal`):
   ```bash
   docker run -p 8000:8000 --add-host=host.docker.internal:host-gateway edu-platform
   ```
4. Откройте `http://localhost:8000` (фронтенд будет раздаваться сервером FastAPI).
