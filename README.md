# EduAI — Образовательная RAG-платформа (ВКР)

Современная образовательная платформа с голосовым ИИ-ассистентом на базе RAG (Retrieval-Augmented Generation). Система умеет:
- Анализировать загруженные преподавателем методические материалы (PDF, DOCX, TXT, MD).
- Отвечать на вопросы студентов с цитированием источников (текстом и голосом).
- Автоматически проверять практические задания (код) и давать фидбэк.
- Генерировать "Резюме урока" и мини-тесты ("Квиз") "на лету".
- Формировать подробную аналитику: активность студентов, статистика ДЗ, слабые темы, производительность ИИ.

### Запуск через Docker (Самый простой способ)

1. Установите [Ollama](https://ollama.com/) и скачайте модели:
```bash
ollama pull qwen2.5
ollama pull nomic-embed-text
```

2. Запустите проект через Docker:
```bash
docker build -t eduai .
docker run -p 8000:8000 --add-host=host.docker.internal:host-gateway eduai
```
3. Откройте `http://localhost:8000` в браузере.

### Запуск вручную (Разработка)

#### Предусловия

- **Python**: 3.10+ (рекомендуется 3.11)
- **Node.js**: 18+ (рекомендуется 20+)
- **LLM**: [Ollama](https://ollama.com/)

### 1) Backend (FastAPI)

Открой PowerShell в `backend/`.

Создай виртуальное окружение и установи зависимости:

```bash
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Создай `.env`:

```bash
copy .env.example .env
```

Запусти API:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Проверка: открой `http://localhost:8000/api/health`.

### 2) Frontend (Vue + Vite)

Открой второй PowerShell в `frontend/`:

```bash
npm install
npm run dev
```

Открой `http://localhost:5173/`.

### 3) Как использовать платформу

#### Для студента:
1. Выберите курс на главной странице.
2. В интерфейсе урока:
   - Читайте материалы лекции.
   - Используйте кнопки **"Резюме урока"** и **"Проверь знания"** для быстрой подготовки (справа под заголовком).
   - Задавайте вопросы ИИ через плавающего ассистента "Кортана" (кнопка в правом нижнем углу). Можно включить режим диалога голосом.
3. Во вкладке **"Задания"** выполняйте ДЗ. ИИ автоматически проверит код и выставит оценку с комментариями.

#### Для преподавателя:
1. На странице курса:
   - Загрузите PDF/TXT/DOCX-материалы через сайдбар. Система проиндексирует их, и ИИ начнёт использовать их для ответов.
2. Во вкладке **"Журнал"**:
   - Смотрите список студентов и их текущие оценки.
3. Во вкладке **"Аналитика"**:
   - Следите за подробными дашбордами (активность по дням, производительность LLM/RAG, успеваемость по ДЗ, слабые темы, активность конкретных студентов).

### Настройка LLM (Ollama)

Если используешь ИИ локально:

1) Установи Ollama и запусти.
2) Подтяни модели:

```bash
ollama pull llama3.2
ollama pull nomic-embed-text
```

Если хочешь OpenAI — переключи в `backend/.env`:

- `LLM_PROVIDER=openai`
- `OPENAI_API_KEY=...`
- (опционально) `EMBEDDING_PROVIDER=openai`
