# 🛠 Руководство для разработчиков (Как всё настроить)

Эта инструкция написана максимально пошагово, чтобы любой человек мог настроить систему под себя, переключить нейросети или адаптировать проект под совершенно другую онлайн-школу.

---

## ЧАСТЬ 1. Как переключать ИИ (Локальные нейросети vs API)

В корне папки `backend` есть скрытый файл `.env`. Откройте его в любом текстовом редакторе (например, в Блокноте или VS Code). В нём хранятся все настройки.

### 1. Выбор текстовой модели (Мозг ИИ)
Система умеет работать как через облачные API (быстро, но нужен интернет и ключи), так и через локальные нейросети (работает на вашей видеокарте через Ollama, бесплатно).

**Чтобы использовать облачное API (OpenRouter / OpenAI):**
1. В файле `.env` найдите строку `USE_LOCAL_LLM` и сделайте её `False`:
   `USE_LOCAL_LLM=False`
2. Вставьте свой ключ от OpenRouter:
   `OPENROUTER_API_KEY=sk-or-v1-ваш-ключ...`
3. Укажите желаемую модель:
   `OPENROUTER_MODEL=openai/gpt-4o-mini` (самая быстрая и умная)

**Чтобы использовать локальную нейросеть (Ollama):**
1. Установите программу Ollama на свой компьютер.
2. Скачайте модель через командную строку: `ollama run llama3` (или `qwen2.5`).
3. В файле `.env` включите локальный режим:
   `USE_LOCAL_LLM=True`
4. Укажите имя вашей локальной модели:
   `OLLAMA_MODEL=llama3`

### 2. Выбор голоса (Синтез речи / TTS)
За генерацию голоса отвечает параметр `TTS_PROVIDER`.

- **Бесплатный голос от Microsoft (Edge TTS):**
  Установите `TTS_PROVIDER=edge`. Работает быстро, нужен просто интернет.
- **Локальный голос (Silero):**
  Установите `TTS_PROVIDER=silero`. Озвучка будет происходить прямо на вашем процессоре/видеокарте (при первом запуске скачается модель на 50 МБ).
- **Клонирование голоса (ElevenLabs):**
  Установите `TTS_PROVIDER=elevenlabs`, укажите ключ `ELEVENLABS_API_KEY` и ID голоса `ELEVENLABS_VOICE_ID`.

## ЧАСТЬ 2. Как адаптировать платформу под ДРУГУЮ школу по шагам

Допустим, вы хотите переделать эту платформу из условной ИТ-школы в **"Школу Английского Языка"** или **"Курсы по Кулинарии"**. Что нужно сделать?

### Шаг 1: Изменение базы знаний (RAG)
ИИ берет знания о курсах из файлов, которые лежат в папке `backend/docs`. 
1. Удалите старые PDF или TXT файлы из `backend/docs`.
2. Загрузите туда методички, правила или учебники вашей новой школы (например, правила грамматики английского).
3. При запуске бэкенда система сама прочитает эти файлы и запишет их в векторную базу (ChromaDB). Теперь ИИ будет отвечать на вопросы учеников, основываясь на ваших документах!

### Шаг 2: Изменение "Характера" ИИ (Промпты)
ИИ изначально настроен вести себя как строгий, но дружелюбный ментор. Вы можете изменить его роль.
1. Откройте файл `backend/app/utils/role_capabilities.py`.
2. Найдите блок текста: *"Ты — дружелюбный ассистент образовательной платформы EduAI..."*
3. Поменяйте текст на свой. Например: *"Ты — британский учитель английского языка. Отвечай вежливо, иногда вставляй английские слова и всегда поправляй ошибки ученика..."*

### Шаг 3: Наполнение базы данных курсами
По умолчанию платформа заполняется тестовыми данными через скрипт `seed.py`.
1. Откройте `backend/app/utils/seed.py`.
2. Найдите блок, где создаются курсы (строка `courses_data = [...]`).
3. Поменяйте названия курсов (например, вместо "Основы Python" напишите "Английский уровень B2").
4. Измените названия уроков и их содержимое там же в коде.
5. Удалите старую базу данных (`backend/test.db`), запустите проект заново, и база наполнится уже новыми курсами!

### Шаг 4: Изменение Дизайна и Логотипов (Фронтенд)
1. Откройте папку `frontend/src/`.
2. Основные цвета и свечения (неон) настраиваются в файле `frontend/src/style.css`. Найдите там секцию `:root` и поменяйте цвета.
3. Логотипы и названия меняются в компонентах (например, в боковом меню `frontend/src/components/Sidebar.vue`). Найдите текст `EduAI` и замените на `MyEnglishSchool`.
4. Вуаля! Платформа полностью адаптирована под ваши нужды.
