# Handoff — EduAI (голосовой ИИ-ассистент для образовательной платформы)

> Передача контекста по проекту ВКР Абрамова М.А. (ЛГТУ, ПИ-22-2).
> Дата: 2026-06-16.

---

## 1. Цель проекта

Разработка **голосового ИИ-ассистента** для образовательной платформы, обеспечивающего интерактивную помощь при прохождении учебных курсов. Главная фишка — **разговор голосом** с ИИ (навигация, RAG-поиск по урокам, проверка ДЗ, отчёты админа).

**Архитектура:** 3 микросервиса
- `platform_service/backend` (порт 8001) — платформа: курсы, уроки, ДЗ, пользователи, auth (JWT)
- `ai_service` (порт 8000) — голосовой ИИ: RAG, Ultravox, навигация, проверка ДЗ, аналитика
- `frontend` (порт 80/nginx) — Vue 3 виджет (GlobalAssistant.vue)

**Роли:** студент, преподаватель, администратор.

## 3. Файлы, с которыми идёт работа

### Бэкенд (`ai_service/app/api/chat.py`)
- `_HIGHLIGHT_RE` (стр. 70) — парсинг тега `[HIGHLIGHT:...]`
- `_strip_nav_tags` — вырезает теги из сохраняемой истории
- `_stream_tokens(..., current_course_id)` — посимвольный перехват тегов + **жёсткий сторож**
- `_process_navigate_action(..., current_course_id)` — блокирует `[NAVIGATE:/courses/<чужой>]` внутри курса
- Оба стрима (`stream_rag_response`, `stream_rag_voice_response`) эмитят события `highlight` и `action`

### Бэкенд (`ai_service/app/services/rag_service.py`)
- `_PROMPT_TEMPLATE` — промпт курса с секциями:
  - правило #4 (строго внутри курса)
  - запрет `[NAVIGATE:/courses/...]` внутри курса
  - секция `### ПОДСВЕТКА ФРАГМЕНТА` (по текущему курсу)

### Фронтенд (`frontend/src/components/GlobalAssistant.vue`)
- `courseIdFromPath()` — извлечение course_id из пути
- `highlightOnPage()` + хелперы (`findDeepestMatch`, `wrapMatch`, `injectHighlightStyle`, `clearHighlights`) — подсветка в DOM
- `runVoiceNavigate()` — **фронт-сторож**: блокирует `navigatePage` на чужой курс
- `runOpenLesson()` — **фронт-сторож**: блокирует `openLesson` на чужой курс
- Оба SSE-цикла (текст + голос) обрабатывают `evt.type === 'highlight'`
- `getPageText()` — читает DOM урока (селекторы `.course-content .content-wrapper` и т.д.)

- `platform_service/backend/app/utils/seed.py` — добавлен админ (`admin1`/`password`)

## 4. Что изменилось в этой сессии

1. **Подсветка фрагментов** (полная цепочка):
   - промпт → парсер тега → SSE-событие `highlight` → DOM-поиск + `<mark>` + анимация во фронте
2. **Жёсткий запрет перехода на чужой курс** — на двух уровнях:
   - бэкенд: `_process_navigate_action` отбрасывает cross-course NAVIGATE
   - фронт: `runVoiceNavigate`/`runOpenLesson` возвращают tool-response «ЗАПРЕЩЕНО»
3. **Сужение подсветки** — сначала до урока, потом откатили до курса
4. **Промпт курса** — правило #4 усилено, навигация на другой курс явно запрещена
5. **Админ** добавлен в `seed.py` платформы
6. **README** переписан под голосовой ИИ как главную цель + админ
7. **INTEGRATION_GUIDE.md** — создан
8. **SEI_Формула.docx** — сгенерирована исправленная формула с нормированным 4-м компонентом

## 5. Что пробовали и не получилось

1. **Сужение подсветки до урока** — модель отказывалась подсвечивать фрагменты «другого урока того же курса». Откатили до ограничения по курсу (фронт всё равно ищет только в DOM текущей страницы).

2. **Промпт как единственное ограничение навигации** — модель всё равно прыгала на React внутри Python (мягкое ограничение не работало). Пришлось добавить жёсткий сторож в коде.

3. **npm-пакет `docx` для нативной формулы** — установка зависла/отменена. Ушли на matplotlib PNG + python-docx.

4. **Доступ к диску E: через os.system с кавычками** — сломалось экранирование. Решили разделением на два скрипта.

5. **«Аналитика прохождения курсов»** — в коде НЕ реализована (нет трекинга просмотров уроков). В ТЗ формулировку сузили до «пользовательская активность при работе с голосовым ИИ-ассистентом» — это честно и покрыто кодом.

6. **Модель SEI с ненормированным 4-м компонентом** — формула из отчёта ломалась (SEI мог уйти за 1). Починили нормировкой `min(.../3, 1)`, пересчитали проверки адекватности.

# → http://localhost  (порт 80)

# Тестовые учётки
# student1 / password   (студент)
# teacher1 / password   (преподаватель)

# Проверки
curl http://localhost:8000/api/health

**Важно для голосового режима:** `ai_service/.env` должен содержать валидный `ULTRAVOX_API_KEY` (по умолчанию в репозитории он есть).
