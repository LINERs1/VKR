# Курс 2: Основы фронтенд-разработки на Vue.js 3

## Введение
Vue.js — это прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. Версия Vue 3 представляет Composition API — новый способ организации логики компонентов, который делает код более читаемым и переиспользуемым.

## Composition API и Реактивность
В отличие от Options API (где использовались секции data, methods, computed), Composition API позволяет группировать логику по функциональности внутри функции `setup()`.
- **ref():** Используется для создания реактивных примитивов (числа, строки, булевые значения). При обращении к значению `ref` в JavaScript нужно использовать свойство `.value`.
- **reactive():** Используется для создания реактивных объектов. В отличие от `ref`, к свойствам можно обращаться напрямую.

## Директивы Vue
Директивы — это специальные атрибуты с префиксом `v-`.
- `v-if` / `v-else`: Условная отрисовка. Элемент удаляется или добавляется в DOM в зависимости от условия.
- `v-for`: Отрисовка списков. Обязательно используйте атрибут `:key` для каждого элемента списка, чтобы Vue мог эффективно обновлять DOM.
- `v-model`: Двустороннее связывание данных (часто используется в формах и инпутах).
- `v-bind` (сокращенно `:`): Связывание атрибута HTML с переменной в JavaScript.

## Жизненный цикл компонента (Lifecycle Hooks)
В Composition API хуки жизненного цикла импортируются из Vue и начинаются с приставки `on`. Например:
- `onMounted`: Вызывается после того, как компонент был смонтирован в DOM. Отличное место для отправки запросов к API.
- `onUnmounted`: Вызывается перед тем, как компонент будет уничтожен. Здесь нужно очищать таймеры и слушатели событий.
