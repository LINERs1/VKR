Введение в Python

Python — высокоуровневый язык программирования общего назначения, созданный Гвидо ван Россумом в 1991 году. Он выделяется простым, читаемым синтаксисом и огромным сообществом разработчиков.

Почему Python популярен:
- Простой и читаемый синтаксис, похожий на обычный английский
- Универсальность: веб-разработка, наука о данных, искусственный интеллект, автоматизация
- Огромная стандартная библиотека и тысячи сторонних пакетов
- Кроссплатформенность: работает на Windows, Linux, macOS

Установка Python:
1. Скачайте Python с официального сайта python.org (версия 3.10 и выше)
2. При установке на Windows отметьте "Add Python to PATH"
3. Проверьте установку командой: python --version

Первая программа:
print("Hello, World!")

Функция print() выводит текст в консоль. Строки заключаются в одинарные или двойные кавычки.

Интерактивный режим (REPL):
Запустите python в терминале — откроется интерактивная консоль. Здесь можно сразу писать и выполнять команды.

Комментарии в Python:
# Это однострочный комментарий
"""
Это многострочный комментарий (строка документации)
Используется для описания функций и классов
"""

Переменные объявляются без указания типа:
name = "Иван"
age = 20
height = 1.75
is_student = True

Python автоматически определяет тип данных переменной.
