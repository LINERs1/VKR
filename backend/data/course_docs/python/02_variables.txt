Переменные и типы данных в Python

Основные типы данных:
1. int — целые числа: x = 10, y = -5
2. float — числа с плавающей точкой: pi = 3.14
3. str — строки: name = "Анна"
4. bool — булевы значения: is_active = True / False
5. list — список (изменяемый): fruits = ["яблоко", "банан", "апельсин"]
6. tuple — кортеж (неизменяемый): coords = (55.75, 37.61)
7. dict — словарь (ключ-значение): student = {"name": "Иван", "age": 20}
8. set — множество (уникальные значения): unique = {1, 2, 3}

Операции со строками:
greeting = "Привет"
name = "Мир"
result = greeting + ", " + name + "!"  # Конкатенация: "Привет, Мир!"
length = len(greeting)  # Длина строки: 6
upper = greeting.upper()  # "ПРИВЕТ"
lower = greeting.lower()  # "привет"

f-строки (форматирование):
name = "Студент"
age = 20
print(f"Меня зовут {name}, мне {age} лет")

Операции со списками:
numbers = [1, 2, 3, 4, 5]
numbers.append(6)        # Добавить элемент в конец
numbers.remove(3)        # Удалить элемент со значением 3
numbers[0]               # Первый элемент (индексация с 0)
numbers[-1]              # Последний элемент
numbers[1:3]             # Срез: элементы с индекса 1 по 2

Операции со словарями:
student = {"name": "Анна", "grade": 5}
student["age"] = 21          # Добавить/обновить ключ
student.get("name")          # Получить значение безопасно
student.keys()               # Все ключи
student.values()             # Все значения
"name" in student            # Проверка наличия ключа: True

Преобразование типов:
int("42")       # строку в число: 42
str(100)        # число в строку: "100"
float("3.14")   # строку в float: 3.14
list((1,2,3))   # кортеж в список

Ввод данных от пользователя:
name = input("Введите имя: ")
age = int(input("Введите возраст: "))  # input всегда возвращает строку
