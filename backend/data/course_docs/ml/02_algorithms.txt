Деревья решений и нейронные сети

Дерево решений (Decision Tree):
Алгоритм, который последовательно задаёт вопросы о признаках и разделяет данные на подгруппы.

Пример: предсказание, пойдёт ли студент на лекцию:
- Интересна ли тема? → Да → Придёт
- Интересна ли тема? → Нет → Есть ли контрольная? → Да → Придёт → Нет → Не придёт

Гиперпараметры:
- max_depth — максимальная глубина (защита от переобучения)
- min_samples_split — минимум объектов для разбиения узла
- criterion — критерий разбиения (gini, entropy)

Случайный лес (Random Forest):
Ансамбль из множества деревьев решений. Каждое дерево обучается на случайной подвыборке данных и случайном наборе признаков. Результат — голосование деревьев.

from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100, max_depth=5)
model.fit(X_train, y_train)

Преимущества: устойчив к переобучению, работает с пропущенными данными.

Нейронные сети (Neural Networks):
Вдохновлены работой мозга. Состоят из слоёв нейронов.

Структура:
- Входной слой (Input layer) — принимает признаки
- Скрытые слои (Hidden layers) — обрабатывают информацию
- Выходной слой (Output layer) — возвращает результат

Каждый нейрон: суммирует взвешенные входы, применяет функцию активации.

Функции активации:
- ReLU: f(x) = max(0, x) — самая популярная
- Sigmoid: f(x) = 1/(1+e^(-x)) — для бинарной классификации
- Softmax — для мультиклассовой классификации

Обучение нейросети — метод обратного распространения ошибки (backpropagation).

Метрики качества моделей:
Классификация:
- Accuracy = (TP + TN) / всего
- Precision = TP / (TP + FP) — точность
- Recall = TP / (TP + FN) — полнота
- F1-score = 2 * Precision * Recall / (Precision + Recall)

Регрессия:
- MAE — средняя абсолютная ошибка
- MSE — среднеквадратичная ошибка
- R² — коэффициент детерминации (1.0 = идеально)

Матрица ошибок (Confusion Matrix):
Показывает количество правильных и ошибочных предсказаний по каждому классу.
