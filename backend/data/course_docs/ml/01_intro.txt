Основы машинного обучения

Машинное обучение (ML) — раздел искусственного интеллекта, где алгоритмы учатся на данных без явного программирования правил.

Типы машинного обучения:
1. Обучение с учителем (Supervised Learning): есть правильные ответы
   - Классификация: определить категорию (спам/не спам)
   - Регрессия: предсказать число (цена квартиры)

2. Обучение без учителя (Unsupervised Learning): ответов нет
   - Кластеризация: сгруппировать похожие объекты
   - Уменьшение размерности: PCA, t-SNE

3. Обучение с подкреплением (Reinforcement Learning): агент обучается через награды и наказания

Основные понятия:
- Признаки (features) — входные данные для модели
- Целевая переменная (target) — то, что предсказываем
- Обучающая выборка (train set) — данные для обучения
- Тестовая выборка (test set) — данные для проверки качества
- Переобучение (overfitting) — модель хорошо на train, плохо на test
- Недообучение (underfitting) — модель плохо на обоих

Линейная регрессия:
Предсказывает числовое значение как линейную комбинацию признаков.
y = w0 + w1*x1 + w2*x2 + ... + wn*xn
Где w — веса (параметры модели), которые подбираются при обучении.

Метод наименьших квадратов минимизирует сумму квадратов ошибок.

Логистическая регрессия:
Несмотря на название, используется для классификации.
Выход — вероятность принадлежности к классу (от 0 до 1).
Использует сигмоид-функцию: σ(x) = 1/(1+e^(-x))
