# Курс 1: Основы веб-разработки на Python и FastAPI

## Введение
Добро пожаловать на курс по основах веб-разработки! FastAPI — это современный и быстрый (высокопроизводительный) веб-фреймворк для создания API с помощью Python на основе стандартных аннотаций типов Python.

## Основные понятия
1. **Маршрутизация (Routing):** Это процесс определения того, как приложение отвечает на клиентский запрос к конкретному эндпоинту. В FastAPI маршрутизаторы создаются с помощью декораторов, таких как `@app.get("/")`.
2. **Pydantic:** Используется для валидации данных и управления настройками. С помощью моделей Pydantic вы описываете типы данных, которые ожидаете получить, и FastAPI автоматически проверяет входящие запросы.
3. **Асинхронность:** FastAPI полностью поддерживает асинхронное программирование. Использование `async def` позволяет приложению не блокироваться при ожидании ввода/вывода (например, ответа от базы данных или стороннего API).

## Запуск приложения
Для запуска приложения на FastAPI используется сервер `uvicorn`. Пример команды:
`uvicorn main:app --reload`
Здесь `main` — это имя файла `main.py`, `app` — это экземпляр FastAPI, а флаг `--reload` заставляет сервер перезапускаться при каждом изменении кода (полезно при разработке).

## Типичные ошибки
- **Ошибка 404 (Not Found):** Означает, что клиент попытался обратиться к несуществующему маршруту.
- **Ошибка 422 (Unprocessable Entity):** Очень частая ошибка в FastAPI. Означает, что тело запроса или параметры не прошли валидацию Pydantic. Убедитесь, что отправляете правильные типы данных!
