# Урок 3. Основы машинного обучения

Машинное обучение (Machine Learning, ML) — это класс методов искусственного интеллекта, характерной чертой которых является не прямое решение задачи, а обучение за счёт применения решений множества сходных задач.

## Основные подходы:

1. **Обучение с учителем (Supervised Learning)**
Алгоритм учится на размеченных данных, где для каждого примера известен правильный ответ. 
*Пример: Классификация писем на «спам» и «не спам» на основе уже отсортированных писем.*

2. **Обучение без учителя (Unsupervised Learning)**
Алгоритм самостоятельно ищет скрытые закономерности в неразмеченных данных.
*Пример: Кластеризация покупателей по их покупательскому поведению (без заранее заданных категорий).*

3. **Обучение с подкреплением (Reinforcement Learning)**
Агент обучается, взаимодействуя со средой. Он совершает действия и получает «награды» за удачные шаги и «штрафы» за ошибки.
*Пример: Обучение ИИ игре в шахматы.*
